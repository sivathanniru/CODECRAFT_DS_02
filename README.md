# Titanic Dataset – Data Cleaning & Exploratory Data Analysis

## Overview
Conducted end-to-end data cleaning, missing-value imputation, and exploratory data analysis on the Titanic passenger dataset to uncover key survival drivers.

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## Key Findings
- Analyzed survival rates across passenger class (`Pclass`), gender, age brackets, and fare distributions using statistical visualizations.
